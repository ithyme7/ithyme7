## Selected projects

### CSV Price Check demo

[csv-price-check-demo](https://github.com/ithyme7/csv-price-check-demo) provides a browser preview using ten fixed fictional items. It compares selling prices by exact SKU, flags problematic rows and lets the reviewer approve eligible changes individually before inspecting the resulting CSV text.

This evaluation demo uses fixed sample data and produces a text preview. It accepts no own-file imports and makes no live shop changes. Its code was developed with generative AI assistance; no runtime AI processes the sample. The [README and licence](https://github.com/ithyme7/csv-price-check-demo#readme) explain local HTTP use and evaluation/sharing permissions. The related [full CSV Price Check tool](https://ithyme7.itch.io/csv-price-check) adds own-file comparison and downloadable updates and audit CSVs.

### Slate UI Kit demo

[slate-ui-kit-demo](https://github.com/ithyme7/slate-ui-kit-demo) is a self-contained HTML/CSS/JavaScript preview of five SVG samples: an Ocean action-button background in normal, hover, pressed and disabled states, plus an arrow-right icon.

The preview embeds its styles, scripts and artwork in one `index.html` file. It needs no framework or installed dependencies and includes keyboard activation, a disabled-state control and a comparison of the four button states. Labels stay separate from the artwork.

- **Inspect:** [preview source](https://github.com/ithyme7/slate-ui-kit-demo/blob/main/index.html).
- **Run:** download the repository and serve `index.html` with a local static web server.
- **Try:** Tab to the sample button, then press Space or Enter; toggle **Enable sample button** to compare the disabled state.
- **Use:** the five samples allow personal and commercial project use under the [included sample licence](https://github.com/ithyme7/slate-ui-kit-demo/blob/main/LICENSE.txt), which restricts standalone asset redistribution and resale.

The geometry, preview code and text were created with generative AI assistance and visually reviewed. The repository contains the five samples and browser preview; it does not include the premium asset collection or native Unreal project.

Related project: the [full Slate UI Kit](https://ithyme7.itch.io/slate-ui-kit) includes additional SVG/PNG assets and a separate editable Unreal menu project. Its product page documents the included files, tests and compatibility limits.
